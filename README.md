# Pipeline GitHub Actions - Node.js

Projeto Node.js demonstrando pipeline CI/CD com **GitHub Actions**.

## 📋 Pré-requisitos

- Node.js (v16, v18 ou v20)
- npm
- Git

## 🚀 Instalação e Execução

```bash
# Clonar repositório
git clone <URL_DO_REPOSITORIO>
cd pipeline-git-actions

# Instalar dependências
npm install

# Executar aplicação
npm start
